# ATTA

Site oficial da ATTA — React + Vite + TypeScript + Tailwind CSS.

## Comandos

- `npm run dev` — ambiente de desenvolvimento
- `npm run build` — build de produção
- `npm run deploy` — publica `dist/` no GitHub Pages

## Dados

Produtos, coleções e looks ficam centralizados em `src/data/`. Imagens em `public/images/`
(ver `public/images/README.md` para a convenção de pastas).
